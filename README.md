# Hi, I'm Sandesh Bhat

Full-Stack Engineer and Founding Engineer at CogniMuse, based in Sirsi, Karnataka, India.

I build production web applications with React, Next.js, TypeScript, Node.js, Supabase and PostgreSQL, and own delivery from requirements and architecture through testing and deployment. I've worked most on offline-first PWAs, role-based systems, performance optimization and mentoring developers.

## Selected work

Most of this is client or company work, so the source code is private.

- **[InvestVidhi](https://www.investvidhi.com/)**: fintech MVP. Architected and built the frontend and backend with Next.js and PostgreSQL.
- **[Cyrcl](https://cyrcl.life/)**: mobile-first PWA MVP with a custom face-recognition API, delivered in a 10-day sprint and handed over to the client.
- **Nurse clinical training PWA**: frontend and offline functionality, including local video caching, client-side API response caching and background sync on reconnect.
- **Office management system for a company secretary firm**: Next.js, TypeScript and Supabase, with invite-only auth, role-specific access for four staff levels, PostgreSQL row-level security, realtime updates, Kanban boards and an auditable activity history.
- **Outreach CRM**: 8-stage lead research pipeline with website audits, AI analysis and approval-gated outreach. Built with Next.js, TypeScript, SQLite, Playwright and Gemini, and backed by 606 tests.
- **[JDS Jungle](https://jdsjungle.com/)**: interactive retail website with GSAP SVG animations and scroll-triggered interactions.

More live builds: [Riya Foundation](https://riyafoundation.org/) · [Tekodyne](https://tekodyne.com/)
